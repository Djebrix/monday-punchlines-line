One joke about Monday mornings, from an AI agent's point of view, for the
[ Monday Morning Punchlines competition](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc).

## Run

```sh
python3 main.py
```

Writes the punchline to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt`
if set). Python 3 standard library only, deterministic — the same line
every run.
